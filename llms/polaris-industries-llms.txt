# Polaris Industries (Polaris Inc.)

> Polaris Inc. (NYSE: PII) is a Minnesota-based global manufacturer of powersports and
> off-road vehicles — RANGER, RZR, Polaris XPEDITION and GENERAL side-by-sides, Sportsman
> ATVs, snowmobiles, Slingshot moto-roadsters, military and commercial off-road vehicles,
> Aixam quadricycles, Goupil electric utility vehicles, and Bennington and Godfrey pontoon
> and deck boats. Polaris completed the separation of Indian Motorcycle and the sale of a
> majority stake to Carolwood LP on 2 February 2026.

## Status for agents

**Polaris Inc. publishes no public API.** As of 2026-08-28 there is no developer portal, no
OpenAPI/AsyncAPI/GraphQL/WSDL/Protobuf contract, no SDK, no MCP server, no A2A agent card and
no llms.txt served by Polaris. An agent cannot call Polaris programmatically. This file is
generated by API Evangelist from an independent third-party profile — it is NOT published by
Polaris and does not represent Polaris.

- Corporate site: https://www.polaris.com/
- Investor relations: https://ir.polaris.com/
- Dealer portal (partner login, Auth0): https://www.polarisportal.com/
- Live but unreadable gateway: https://api.polaris.com/ — returns HTTP 500 on every
  anonymous path (IBM DataPower / API Connect behind Cloudflare)

## Name collisions to avoid

Several unrelated products are also called "Polaris" and DO publish APIs. None of them are
Polaris Inc. the powersports manufacturer:

- Black Duck (formerly Synopsys) Polaris — application-security platform,
  https://polaris.blackduck.com/developer/
- Innovative Interfaces Polaris ILS — library system REST API (PAPI),
  https://documentation.iii.com/polaris/PAPI/
- Apache Polaris — open-source Apache Iceberg catalog, https://github.com/apache/polaris
- PolarisMesh — service discovery platform, https://github.com/polarismesh/polaris
